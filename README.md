# 爆款封面结构反推助手

看到一张喜欢的小红书商品封面，想借鉴它的场景、陈列和光线，又说不清好在哪里——把图发给它，它会把封面的画面结构整理成一段可以直接拿去 AI 生图的中文提示词。你再配上自己的商品图生图，就能借用这张封面的结构，商品换成你自己的。

## 先选你的用法

### 用法一：你用支持 Skill 的 Agent（一次装好，之后只发图）

这个包就是一个建好的专用项目。AGENTS.md 是这个项目的规矩：只处理图片，别的不干；Skill 是具体干活的方法。在项目里发图片，就会自动按这套规矩和方法处理，不用再输入任何指令。

用 Codex 最简单，整包直接用：

1. 下载这个包，解压。
2. 用 Codex 打开解压出来的文件夹（就是有 AGENTS.md 的这一层）。
3. 在对话里上传 1–5 张想参考的商品封面图。

就这三步。之后每次只发图，就会逐张得到一段结构反推提示词。

用 Claude Code、WorkBuddy、豆包的 Agent 版等其他工具也可以，只是多一步：把 `.agents/skills/bxqn-xhs-image-prompt` 文件夹导入或放进那个工具的技能目录，AGENTS.md 放到你的项目根目录，效果一样。也可以把这个包直接发给你的 Agent，让它帮你装好。

已经装过 Skills 工具的，在终端运行这一条命令，就能把 Skill 装到你所有的 Agent 里：

```bash
npx -y skills add boxiqingnian-bot/bxqn-xhs-image-prompt -g --all
```

### 用法二：你不用 Agent，用聊天 AI（不用装任何东西）

豆包、通义千问、Kimi 等能看图的聊天 AI 都可以这样用：

1. 打开豆包（doubao.com 或豆包 App）。
2. 打开这个包里的 `豆包直接使用提示词.md`，把里面代码块的全部内容复制下来，发给它。
3. 它回复后，上传 1–5 张想参考的商品封面图。

之后每次只发图就行。每张图会得到一段提示词，后续生图时，再把提示词配上你自己的商品图使用。

说明一句：聊天版只靠这一段提示词约束，识图效果和稳定性会比用法一略差一些。对效果要求高，建议优先用豆包，或直接用用法一的 Agent 版。

## 它给你的提示词长什么样

一段自然中文，按场景、视角、人物或手部动作、商品陈列、关键环境、光线和质感的顺序写好。其中商品只会写成“如图所示的包包”这样的宽泛品类，不会把参考封面里商品的颜色、材质、品牌和造型写进去——因为生图时要用的是你自己的商品图。

## 它只做这一件事

- 只做结构反推：不做同风格裂变，不生成标题，不分析这张图为什么能爆。
- 只写画面里清楚看得见的信息，看不清的不猜。
- 一次最多处理 5 张图，逐张独立处理，不把不同图片的元素混在一起。

## 包里有什么

```text
AGENTS.md                                      Codex 打开这个项目时生效的规则
.agents/skills/bxqn-xhs-image-prompt/SKILL.md       爆款封面结构反推skill
.agents/skills/bxqn-xhs-image-prompt/agents/openai.yaml
                                                Skill 的界面信息（显示名、简介）
豆包直接使用提示词.md                           不用 Codex 时，粘贴到豆包的提示词
```

用法一靠前两个文件，用法二靠最后一个文件，核心方法是同一套。
